Como jogar

  1. Conecte o celular

    Aponte a câmera do celular para o QR code no canto da tela e toque em Ligar raquete.

  2. Segure como raquete

    Celular em pé, com a parte de trás virada para a tela. Toque em Calibrar apontando para o computador.

  3. Saque

    Dê um toque para cima com o celular (ou o botão Sacar) para lançar a bola. Depois, rebata!

  4. Rebata com força e efeito

    Quanto mais rápido o golpe, mais rápida a bola. Gire para os lados para mirar. Golpe de baixo para cima faz topspin, de cima para baixo faz backspin, de lado faz spin lateral.

Sem celular? Use o mouse: mova para posicionar, clique para rebater. Segure W, S, A ou D enquanto clica para dar efeito. Espaço lança a bola no saque.
